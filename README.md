
# 📋 Project View
    An app for analyzing Print-on-Demand opportunities before you start designing and working on a product. You enter your idea, and the app turns it from an idea in your head into a real-world business analysis, helping you determine whether it’s worth implementing or not. It also provides daily opportunities that the tool discovers by analyzing the market.
    
---

# 📋 Project Structure
   \scraperServer
        - Responsible about the Scraping data we need to get insight of the market.
    \mainServer
        - Responsible about the system logic so we can know which User, which plans and ..etc.
    \client 
        - The frontend screens
